## Featured projects

### [Used car price prediction](https://github.com/anzhelika-belyakova/used-car-price-prediction)

Regression pipeline for estimating used-vehicle prices from historical listings.

- LightGBM, XGBoost, CatBoost, scikit-learn
- 342K+ modeling observations
- cross-validation-based model selection
- final test RMSE: **EUR 1,569.63**
- leakage-aware preprocessing, residual diagnostics, and feature analysis

### [California housing value prediction with PySpark](https://github.com/anzhelika-belyakova/california-housing-value-prediction-pyspark)

Distributed regression workflow for California housing data using Spark MLlib.

- PySpark and Spark MLlib
- training-only imputation and reproducible pipelines
- categorical encoding and feature assembly
- residual diagnostics and nonlinear feature experiments

### [Customer activity decline prediction](https://github.com/anzhelika-belyakova/customer-activity-decline-prediction)

Classification and customer segmentation project for identifying customers at risk of declining activity.

- scikit-learn, Optuna, SHAP
- stratified cross-validation and hyperparameter tuning
- out-of-fold risk scoring
- risk-and-profit customer segmentation

### [Employee satisfaction and turnover prediction](https://github.com/anzhelika-belyakova/employee-satisfaction-turnover-prediction)

Two-stage ML workflow connecting job-satisfaction prediction with employee-turnover classification.

- regression and classification pipelines
- OptunaSearchCV
- random forest final classifier
- permutation importance and business-oriented error analysis

### [Oil well location optimization](https://github.com/anzhelika-belyakova/oil-well-location-optimization)

Machine learning and financial-risk analysis for selecting an oil-development region.

- linear regression
- bootstrap simulation
- expected-profit analysis
- loss-risk constrained decision making

## Portfolio principles

Across my projects, I focus on:

- preventing data leakage;
- separating model selection from final test evaluation;
- using reproducible preprocessing pipelines;
- comparing models with appropriate validation strategies;
- analyzing residuals and failure modes rather than reporting a single metric;
- documenting assumptions and limitations explicitly;
- connecting model results with practical decision-making.
